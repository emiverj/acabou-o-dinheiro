# Dados do modo Copa do Mundo

Scripts usados para gerar `players_copa.js`: `model.py` (notas por versão), `select.py` (escolha das ~890 versões e régua final), `talent.py` (picos curados), `user_ovr.json` (notas ajustadas pelo Marcos, prevalecem), `sq2026.txt` (convocações de 2026).
Fontes: Fjelstul World Cup Database e openfootball/worldcup (GitHub).
